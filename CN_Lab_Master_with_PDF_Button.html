Simple LAN (2 PCs + Switch)

▾
⭐ EASY

Aim

Create a LAN with 2 PCs + 1 switch; verify with ping.

   [PC0]            [PC1]
192.168.1.1     192.168.1.2
      \             /
       \           /
      ┌──────────────┐
      │   Switch0    │
      │    (2960)    │
      └──────────────┘
     Fa0/1      Fa0/2

Build steps

  • Drag 2 PCs + Switch 2960 → connect copper straight-through: PC0 Fa0↔Fa0/1, PC1 Fa0↔Fa0/2
  • PC IPs: 192.168.1.1 & .2, mask 255.255.255.0
📸 How to get the OUTPUT (screenshot #1):

  2. Type: ping 192.168.1.2 → Enter
  3. 4 replies appear → take screenshot

▾
⭐⭐⭐⭐ HARDEST

Aim

Site-to-site IPSec VPN between 2 branches over ISP.

[PC1]────[Router1]═══S═══[ ISP ]═══S═══[Router2]────[PC2]
 .1.10      │ 10.0.0.1      │              │ 10.0.0.6    .2.10
            │            10.0.0.2        10.0.0.5
        192.168.1.1  └── WAN 10.0.0.0/30 ──┘  192.168.2.1
        (Branch A)                          (Branch B)
═══S═══ = Serial DCE cable (clock side: Router1 & Router2)
⚠️ 3× 1941 routers + add HWIC-2T module to all 3 (Physical→power OFF→drag module→ON). Serial links stay RED until IPs+clock rate are set — that's normal!
enable
configure terminal
interface FastEthernet0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
interface Serial0/0/0
ip address 10.0.0.1 255.255.255.252
clock rate 64000
no shutdown
exit
ip route 192.168.2.0 255.255.255.0 10.0.0.2
crypto isakmp policy 10
encryption aes
hash sha
authentication pre-share
group 2
lifetime 86400
exit
crypto isakmp key cisco123 address 10.0.0.6
crypto ipsec transform-set MYSET esp-aes esp-sha-hmac
crypto map MYMAP 10 ipsec-isakmp
set peer 10.0.0.6
set transform-set MYSET
match address 101
exit
access-list 101 permit ip 192.168.1.0 0.0.0.255 192.168.2.0 0.0.0.255
interface Serial0/0/0
crypto map MYMAP
end
enable
configure terminal
interface Serial0/0/0
ip address 10.0.0.2 255.255.255.252
no shutdown
interface Serial0/0/1
ip address 10.0.0.5 255.255.255.252
no shutdown
end
enable
configure terminal
interface FastEthernet0/0
ip address 192.168.2.1 255.255.255.0
no shutdown
interface Serial0/0/0
ip address 10.0.0.6 255.255.255.252
clock rate 64000
no shutdown
exit
ip route 192.168.1.0 255.255.255.0 10.0.0.5
crypto isakmp policy 10
encryption aes
hash sha
authentication pre-share
group 2
lifetime 86400
exit
crypto isakmp key cisco123 address 10.0.0.1
crypto ipsec transform-set MYSET esp-aes esp-sha-hmac
crypto map MYMAP 10 ipsec-isakmp

set transform-set MYSET

access-list 101 permit ip 192.168.2.0 0.0.0.255 192.168.1.0 0.0.0.255

📸 How to get the OUTPUT (2 screenshots):
  1. PC1 → Command Prompt → ping 192.168.2.10 → 1st ping mostly timeouts (tunnel negotiating, ~30s) → ping again → 4 replies → screenshot

Aim

Configure VLANs 10/20 + trunk; verify.

[PC1][PC2][PC3]          [PC4]
 VLAN 10 (Faculty)     VLAN 20 (Students)
    │    │    │           │
   Fa0/2 Fa0/3 Fa0/4    Fa0/5
    └─────┼────┘           │
     ┌────┴────────────────┴──┐
     │ SW1 Gi0/1 ══TRUNK══ Gi0/1 SW2 │
     └────────────────────────┘
     ══ trunk = 802.1Q, carries VLAN 10,20 ══
enable
configure terminal
vlan 10
name Faculty
exit
vlan 20
name Students
exit
interface range fa0/2-4
switchport mode access
switchport access vlan 10
exit
interface fa0/5
switchport mode access
switchport access vlan 20
exit
interface g0/1
switchport mode trunk
switchport trunk encapsulation dot1q
switchport nonegotiate
switchport trunk allowed vlan 10,20
exit
copy run start
📸 How to get the OUTPUT (2 screenshots):
  1. Switch CLI → show vlan brief → screenshot (VLAN 10 & 20 visible with ports)
  2. Then → show interfaces trunk → screenshot (Gig0/1 trunking 802.1q, allowed 10,20)
  3. Bonus: PC(VLAN10) ping PC(VLAN10)=✔ success; PC(VLAN10)→PC(VLAN20)= ✖ needs router (viva point!)

3d — OSPF (Link-State Routing)

▾
⭐⭐⭐ MEDIUMEXAM FAVORITE

Aim

OSPF — routers learn routes AUTOMATICALLY (vs static).

[PC0]──[R1]═══ 10.0.0.0/30 ═══[R2]──[PC1]
.1.10   │ G0/0:192.168.1.1 │  G0/0:192.168.2.1 :.2.10
GW .1.1 │ G0/1: 10.0.0.1   │  10.0.0.2 :G0/1  GW .2.1
        └── OSPF area 0 ───┘
enable
configure terminal
interface g0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
exit
interface g0/1
ip address 10.0.0.1 255.255.255.252
no shutdown
exit
router ospf 1
network 192.168.1.0 0.0.0.255 area 0
network 10.0.0.0 0.0.0.3 area 0
exit
enable
configure terminal
interface g0/0
ip address 192.168.2.1 255.255.255.0
no shutdown
exit
interface g0/1
ip address 10.0.0.2 255.255.255.252
no shutdown
exit
router ospf 1
network 192.168.2.0 0.0.0.255 area 0
network 10.0.0.0 0.0.0.3 area 0
exit
📸 How to get the OUTPUT (3 screenshots):
  1. Router1 CLI → show ip ospf neighbor → wait ~30s → must show state FULL/DR → screenshot 🏆
  2. Then → show ip route → must see O 192.168.2.0/24 (O = OSPF-learned!) → screenshot
  3. PC0 → ping 192.168.2.10 → 4 replies → screenshot
Router1#show ip ospf neighbor

Neighbor ID     Pri   State     Dead Time   Address    Interface
10.0.0.2          1   FULL/DR   00:00:33    10.0.0.2   GigabitEthernet0/1

Router1#show ip route
C    10.0.0.0/30 is directly connected, GigabitEthernet0/1
C    192.168.1.0/24 is directly connected, GigabitEthernet0/0
O    192.168.2.0/24 [110/2] via 10.0.0.2, GigabitEthernet0/1

C:\>ping 192.168.2.10
Reply from 192.168.2.10: bytes=32 time=1ms TTL=127 (×4, 0% loss)
⚠️ OSPF uses WILDCARD masks (inverse of subnet): 255.255.255.0 → 0.0.0.255 • /30 link → 0.0.0.3
💡 FULL/DR = neighbor adjacency complete. OSPF floods link-state info → builds map → runs Dijkstra's shortest-path. Dynamic = adapts to failures.

Result: OSPF configured; routes learned dynamically.

3e — NS2 Study + Congestion Simulation

▾
THEORY+TCL

Aim

Study NS2; simulate TCP congestion control.

    [n0]───10Mb───[n1]───1Mb───[n2]
      │            │             │
     TCP Reno   bottleneck!    TCPSink
      └────── FTP traffic ──────┘
  1Mb link fills → queue (limit 10) overflows → packets DROPPED

Key theory (viva)

  • Throughput = successful delivery rate (bit/s) • Delay = src→dst time • Packet loss = queue overflow
